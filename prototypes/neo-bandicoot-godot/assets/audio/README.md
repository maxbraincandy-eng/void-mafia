# Audio placeholders

Drop real audio here as the project grows. Phase-1 code doesn't play sound yet;
these are the slots later phases will wire up:

- jump.wav        — player jump / double jump
- attack.wav      — spin attack
- collect.wav     — coin / fruit pickup
- damage.wav      — player takes a hit
- music_level.ogg — looping background music

Keep SFX as .wav (short) and music as .ogg (streamed, looping).
